# Predicting Code Quality using Machine Learning

## Overview
This project predicts whether a code snippet is buggy or safe using ML.

## Features Used
- TF-IDF (token-based)
- Static metrics (LOC, loops, conditions)
- Structural patterns (NULL, pointers, etc.)

## Models
- Logistic Regression
- Random Forest
- SVM

## How to Run

```bash
pip install -r requirements.txt
python main.py
python predict.py
